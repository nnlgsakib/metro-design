# metro-splittone

Color grading split-toning effect. Apply independent hue and saturation to highlights and shadows with adjustable balance.

## Parameters

| Parameter            | Type   | Default | Description                   |
|----------------------|--------|---------|-------------------------------|
| HighlightsHue        | float  | 0.0     | Highlight hue tint            |
| HighlightsSaturation | float  | 0.5     | Highlight saturation          |
| ShadowsHue           | float  | 0.0     | Shadow hue tint               |
| ShadowsSaturation    | float  | 0.5     | Shadow saturation             |
| Balance              | float  | 0.5     | Highlights/shadows balance    |
| Mix                  | float  | 1.0     | Effect blend amount           |
