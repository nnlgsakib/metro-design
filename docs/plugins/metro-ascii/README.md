# metro-ascii

Convert video frames to ASCII art in real time. Maps luminance to a configurable character set.

## Parameters

| Parameter | Type   | Default       | Description                     |
|-----------|--------|---------------|---------------------------------|
| Charset   | string | " .:-=+*#%@"  | Characters used for luminance mapping |
| Opacity   | float  | 1.0           | Output opacity                  |
